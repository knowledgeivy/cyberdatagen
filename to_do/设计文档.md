# LLM生成网络安全合成数据失效原因研究 - 设计文档

## 项目概述

本项目研究LLM生成的网络安全合成数据失效原因，通过embedding分析和机器学习对比来解释为什么合成数据在某些情况下无法有效提升模型性能。

### 研究目标
- 分析LLM生成的合成数据与真实数据的embedding差距
- 识别未被合成数据覆盖的真实数据区域
- 找出影响分类效果的距离临界值
- 提供数据增强策略的改进建议

## 实验流程设计

### 阶段1-2: 基于CEAS-08的embeddings分析

#### 步骤1: 数据准备 (batch1_prepare_base_data.py)
1. 从CEAS-08数据集采样5K恶意+5K良性邮件
2. 创建1K恶意种子样本（通过分组策略）
3. 随机选择1K良性种子样本
4. 生成唯一ID标注（CEAS08_REAL_M_xxxxx格式）

#### 步骤2: 合成数据生成 (batch1_generate_synthetic.py)
使用三种重写策略生成合成数据：
- **rewrite**: 基础重写，保持攻击意图改变表达
- **rewrite_strong**: 强化版本，更难检测
- **rewrite_weak**: 弱化版本，更容易检测

LLM配置：
- 模型: gpt-4o-mini
- 并发: 10 workers
- 重试: 最多3次

#### 步骤3: Embedding分析 (batch1_embedding_analysis.py)
1. 使用sentence-transformers (all-MiniLM-L6-v2)生成embeddings
2. PCA和t-SNE降维可视化
3. 识别未覆盖的真实数据点：
   - 使用最近邻方法找到距离合成数据较远的真实数据
   - DBSCAN聚类识别孤立的真实数据点
   - 设置阈值（80百分位）识别未覆盖区域

#### 步骤4: 增强数据准备 (batch2_prepare_enhanced_data.py)
1. 提取batch1中未被覆盖的真实数据ID
2. 使用余弦距离找到相似样本扩展到1K
3. 创建增强种子集（优先未覆盖+相似样本）

#### 步骤5: 增强合成数据生成 (batch2_generate_synthetic.py)
1. 基于增强种子生成新的合成数据
2. 使用相同的三种重写策略
3. 生成独特ID（CEAS08_SYN2_xxx格式）

#### 步骤6: 对比分析
1. 比较batch1和batch2的覆盖率改进
2. 机器学习分类效果对比
3. Embedding分布差异分析

### 阶段3: 距离临界值分析（规划中）

#### 目标
找出使分类精度大幅下降的距离临界值

#### 实施策略
1. 选择距离稍远的真实数据作为种子
2. 测试不同距离阈值对生成效果的影响
3. 识别分类性能急剧下降的临界点

## 技术架构

### 数据流
```
原始数据 → 采样 → 种子生成 → LLM重写 → 合成数据
                                ↓
真实数据 → Embedding → 覆盖分析 → 未覆盖识别
                                ↓
未覆盖数据 → 增强种子 → 新一轮生成 → 改进对比
```

### Embedding分析流程
```
文本数据 → SentenceTransformer → 384维向量
             ↓
PCA/t-SNE降维 → 2D可视化
             ↓
距离计算 → 覆盖分析 → 未覆盖识别
```

### ID命名规范
- 真实数据: `CEAS08_REAL_{B|M}_{5位数字}`
- Batch1合成: `CEAS08_SYN1_{变体}_{种子ID}_{样本序号}`
- Batch2合成: `CEAS08_SYN2_{变体}_{种子ID}_{样本序号}`

## 关键算法

### 1. 未覆盖数据识别算法
```python
# 最近邻方法
nbrs = NearestNeighbors(n_neighbors=1, metric='cosine')
nbrs.fit(synthetic_embeddings)
distances, _ = nbrs.kneighbors(real_embeddings)
threshold = np.percentile(distances, 80)  # 前20%最远距离
uncovered_mask = distances > threshold
```

### 2. 相似样本扩展算法
```python
# 计算未覆盖样本到所有真实样本的距离
distances_matrix = cosine_distances(base_embeddings, uncovered_embeddings)
min_distances = np.min(distances_matrix, axis=1)
# 按距离排序选择最相似的样本
sorted_indices = np.argsort(min_distances)
```

### 3. DBSCAN孤立点检测
```python
dbscan = DBSCAN(eps=0.15, min_samples=3, metric='cosine')
cluster_labels = dbscan.fit_predict(real_embeddings)
isolated_mask = cluster_labels == -1  # 噪声点即孤立样本
```
