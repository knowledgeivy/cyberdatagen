# 批次4重新设计方案

## 问题识别

### 原实验设计的重大缺陷
1. **数据泄露问题**: 复用batch1的固定测试集，可能与训练数据重叠
2. **数据源混淆**: 使用batch1已处理数据而非原始CEAS-08数据
3. **实验独立性**: 未从原始数据集进行干净的train/test划分

### 用户核心关切
> "合成数据有重合没关系，我担心的是test数据里，理所应当和training data不重合"
> "你似乎复用batch 1的数据，没有重新调用我的代码，用LLM生成新的synthetic data吧？"

---

## 重新设计的实验框架

### 🎯 核心原则
1. **从原始CEAS-08数据开始**: 完全独立的数据处理流程
2. **严格train/test分离**: 确保测试数据完全独立
3. **新鲜合成数据生成**: 基于新划分数据重新生成合成样本
4. **实验设计完整性**: 保持不平衡数据和内部距离分析的科学目标

## 新实验流程设计

### Phase 0: 原始数据预处理和划分 ✅ **已完成**
```
输入: raw/SevenPhishingEmailDataset/CEAS-08.csv (1,305,706 样本)
操作:
1. 数据清洗和格式化
2. 按8:2比例进行train/test划分 (随机种子=2025)
3. 提取恶意和良性样本子集
4. 生成embedding向量

输出:
- data/batch4_fresh/train_set.csv.gz (1,044,565样本)
- data/batch4_fresh/test_set.csv.gz (261,141样本) 
- data/batch4_fresh/train_malicious.csv.gz (17,463样本)
- data/batch4_fresh/train_benign.csv.gz (1,027,102样本)
```

### Phase 1: 质心计算和内部距离分层 ✅ **已完成**
```
输入: data/batch4_fresh/train_malicious.csv.gz
操作:
1. 计算训练集恶意样本的embedding质心
2. 计算每个样本到质心的余弦距离
3. 按四分位数分层: Core/Inner/Outer/Edge
4. 可视化分层结果

输出:
- data/batch4_fresh/malicious_centroid.json
- data/batch4_fresh/stratified_layers/ (4层各4,366样本)
  - core_samples.csv (25%最接近质心)
  - inner_samples.csv 
  - outer_samples.csv
  - edge_samples.csv (25%最远离质心)
```

### Phase 2: 分层合成数据生成 ✅ **已完成**
```
输入: data/batch4_fresh/stratified_layers/*.csv
操作:
1. 从每层采样100个种子样本
2. 使用gpt-4.1-mini模型生成3种prompt变体的合成数据
3. 总计1,200次API调用，验证生成质量和成功率

输出:
- data/batch4_fresh/synthetic/ (每层300个合成样本)
  - core_synthetic.csv
  - inner_synthetic.csv  
  - outer_synthetic.csv
  - edge_synthetic.csv
```

### Phase 3: 不平衡数据集构建 ✅ **已完成**
```
输入: 
- data/batch4_fresh/train_*.csv (真实数据)
- data/batch4_fresh/synthetic/*.csv (合成数据)
- data/batch4_fresh/test_set.csv (固定测试集)

操作:
1. 构建5个数据组 (real_only + 4个synthetic层)
2. 按4个比例构建训练集 (5%, 10%, 15%, 20% 恶意数据)
3. 所有配置使用相同的独立测试集

输出:
- data/batch4_fresh/datasets/ (20个配置)
  - real_only_5pct/ → real_only_20pct/
  - core_5pct/ → core_20pct/
  - inner_5pct/ → inner_20pct/
  - outer_5pct/ → outer_20pct/
  - edge_5pct/ → edge_20pct/
```

### Phase 4: 统一embedding和可视化 ✅ **已完成**
```
输入: data/batch4_fresh/datasets/*/
操作:
1. 为所有20个数据集配置生成embedding向量
2. 分析不同数据组和比例的embedding分布
3. 可视化合成数据与真实数据的对比

输出:
- data/batch4_fresh/phase4_embeddings/ (所有embedding向量)
- data/batch4_fresh/phase4_visualizations/ (PCA和t-SNE可视化)
- data/batch4_fresh/phase4_analysis/ (综合分析报告)
```

### Phase 5: 模型训练和评估 ✅ **已完成**
```
输入: data/batch4_fresh/datasets/*/
操作:
1. 40个实验配置的RF和SVM训练
2. 使用固定测试集评估
3. 计算不平衡数据专用指标

输出:
- data/batch4_fresh/phase5_results/ (所有实验结果)
- data/batch4_fresh/phase5_visualizations/ (性能对比图表)
- data/batch4_fresh/phase5_analysis/ (综合分析报告)
```

## 🎉 实验结果摘要

### 核心发现
1. **SVM性能显著优于RandomForest**: 平均F1-Score 0.983 vs 0.831
2. **最佳配置**: real_only_20pct + SVM (F1: 0.992)
3. **合成数据效果**: 与真实数据性能相当 (F1: 0.908 → 0.907)
4. **性能范围**: F1分数从0.702到0.992，显示配置间显著差异
