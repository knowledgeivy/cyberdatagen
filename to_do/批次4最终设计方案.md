## 📊 详细数据流设计

### Phase 0: 原始数据预处理和划分
```
输入: CEAS-08.csv (1,305,706 samples)

操作:
1. 数据清洗和标准化
2. 严格8:2 train/test划分 (random_state=2025)
3. 提取训练集中的malicious和benign数据

输出:
- data/batch4_fresh/raw_train_set.csv (~104万样本)
  └── ID格式: train_real_{index}
- data/batch4_fresh/raw_test_set.csv (~26万样本)  
  └── ID格式: test_real_{index}
- data/batch4_fresh/train_malicious.csv (~52万恶意样本)
  └── ID格式: train_real_mal_{index}
- data/batch4_fresh/train_benign.csv (~52万良性样本)
  └── ID格式: train_real_ben_{index}
```

### Phase 1: 恶意数据embedding和分层
```
输入: data/batch4_fresh/train_malicious.csv

操作:
1. 对训练集恶意数据生成384维embedding
2. 计算embedding质心
3. 按余弦距离四分位数分层

输出:
- data/batch4_fresh/malicious_embeddings.npy
- data/batch4_fresh/malicious_centroid.json
- data/batch4_fresh/stratified_layers/
  ├── core_samples.csv (25%, ID: train_real_mal_core_{index})
  ├── inner_samples.csv (25%, ID: train_real_mal_inner_{index})
  ├── outer_samples.csv (25%, ID: train_real_mal_outer_{index})
  └── edge_samples.csv (25%, ID: train_real_mal_edge_{index})
```

### Phase 2: 分层合成数据生成
```
输入: data/batch4_fresh/stratified_layers/*.csv

操作:
1. 每层采样100个种子样本
2. 每个种子用3个prompt变体生成合成数据:
   - rewrite: 基础重写变体
   - rewrite_strong: 强化变体（更难检测）
   - rewrite_weak: 弱化变体（更易检测）
3. 严格ID标注体系

输出:
- data/batch4_fresh/synthetic/
  ├── core_synthetic.csv (300样本)
  │   └── ID: synth_core_{seed_id}_{prompt_type} 
  ├── inner_synthetic.csv (300样本)
  │   └── ID: synth_inner_{seed_id}_{prompt_type}
  ├── outer_synthetic.csv (300样本)
  │   └── ID: synth_outer_{seed_id}_{prompt_type}
  └── edge_synthetic.csv (300样本)
      └── ID: synth_edge_{seed_id}_{prompt_type}

其中prompt_type = {rewrite, rewrite_strong, rewrite_weak}

总计: 1200个合成样本
API调用: 1200次 (100种子 × 4层 × 3个prompt)
```

### Phase 3: 不平衡数据集构建
```
输入: 
- 分层真实恶意数据
- 分层合成恶意数据  
- 真实良性数据
- 固定测试集

数据组配置:
1. real_only: 100%真实恶意数据
2. core_mix: 50%真实 + 50%core合成数据
3. inner_mix: 50%真实 + 50%inner合成数据
4. outer_mix: 50%真实 + 50%outer合成数据
5. edge_mix: 50%真实 + 50%edge合成数据

比例配置: 5%, 10%, 15%, 20%恶意数据比例
数据集大小: 每个10,000样本

输出:
- data/batch4_fresh/datasets/
  └── {group}_{ratio}pct/
      ├── train.csv (10,000样本)
      ├── test.csv (固定测试集)
      └── config.json (元数据)

总计: 20个数据集配置
```

### Phase 4: 统一embedding和可视化
```
输入: 所有真实和合成数据

操作:
1. 对所有数据生成统一embedding
2. 统一降维(PCA/t-SNE)
3. 可视化不同类别的分布

输出:
- data/batch4_fresh/unified_analysis/
  ├── all_embeddings.npy (统一embedding空间)
  ├── visualization_data.csv
  └── distribution_plots/
```

### Phase 5: 模型训练和评估
```
输入: 20个数据集配置

操作:
1. RF和SVM模型训练
2. 固定测试集评估
3. 统计显著性检验

输出:
- data/batch4_fresh/results/
  ├── performance_matrix.csv
  ├── statistical_tests.json
  └── analysis_report.md
```

## 🔍 关键参数确定

### LLM生成参数
- **种子采样**: 每层100个种子
- **生成策略**: 1-to-3 (每种子3个prompt变体)
- **Prompt策略**: 复用batch1-3验证的3个prompt:
  - `rewrite`: 基础重写变体
  - `rewrite_strong`: 强化变体（更难检测）
  - `rewrite_weak`: 弱化变体（更易检测）
- **API调用量**: 1,200次 (100种子 × 4层 × 3个prompt)
- **预估成本**: $3-5

### 数据比例配置
```
每个10,000样本的数据集构成:
- 5%恶意比例: 500恶意 + 9,500良性
- 10%恶意比例: 1,000恶意 + 9,000良性  
- 15%恶意比例: 1,500恶意 + 8,500良性
- 20%恶意比例: 2,000恶意 + 8,000良性

恶意样本构成 (以core_mix为例):
- 50%真实恶意样本 (从训练集采样)
- 50%core层合成样本 (从300个core合成样本采样)
```

### 合成数据充足性验证
```
最大需求: 20%比例的2,000个恶意样本
- 50%真实: 1,000个 (从52万训练样本采样，充足)
- 50%合成: 1,000个 (每层300个合成样本，充足)

结论: 1,200个合成样本足够支持所有实验配置
```
