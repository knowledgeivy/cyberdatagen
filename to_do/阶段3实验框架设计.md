# 阶段3距离临界值分析实验框架设计

## 🎯 实验目标

找出**距离临界值**：当真实数据与合成数据的embedding距离超过某个临界点时，LLM生成的合成数据质量急剧下降，导致分类性能大幅降低的关键距离值。

## 🔬 核心假设

1. **距离效应假设**: 种子样本距离现有合成数据越远，LLM生成的新合成数据质量越差
2. **临界点存在假设**: 存在一个或多个关键距离阈值，超过后性能急剧下降
3. **可量化假设**: 这种性能下降可以通过分类准确率等指标量化测量

## 📊 实验设计方案

#### 1.2 种子选择算法
```python
def select_seeds_by_distance_range(real_data, existing_synthetic, distance_range, n_seeds=50):
    """
    为每个距离区间选择种子样本
    
    Args:
        real_data: 5K真实数据
        existing_synthetic: 现有合成数据 (batch1+batch2)
        distance_range: (min_dist, max_dist) 距离区间
        n_seeds: 每个区间选择的种子数量
    
    Returns:
        selected_seeds: 选中的种子样本列表
    """
    min_dist, max_dist = distance_range
    candidates = []
    
    for real_sample in real_data:
        # 计算到现有合成数据的最小距离
        min_distance = calculate_min_cosine_distance(real_sample, existing_synthetic)
        
        # 检查是否在目标距离区间内
        if min_dist <= min_distance < max_dist:
            candidates.append({
                'sample': real_sample,
                'distance': min_distance,
                'data_id': real_sample['data_id']
            })
    
    # 按距离排序，选择代表性样本
    candidates.sort(key=lambda x: x['distance'])
    
    # 分层选择：从区间内均匀采样
    n_candidates = len(candidates)
    if n_candidates == 0:
        return []
    
    step = max(1, n_candidates // n_seeds)
    selected = [candidates[i] for i in range(0, min(n_candidates, n_seeds * step), step)]
    
    return selected[:n_seeds]
```

### 2. 性能评估指标体系

#### 2.1 核心指标
- **分类准确率** (Accuracy): 主要评估指标
- **F1-Score** (Macro/Weighted): 平衡性评估
- **AUC-ROC**: 分类质量评估
- **生成成功率**: LLM生成质量指标

#### 2.2 距离质量指标
- **平均距离偏差**: 生成样本与种子样本的距离差异
- **覆盖率增量**: 新生成数据对未覆盖区域的改善程度
- **分布一致性**: 生成数据与真实数据分布的相似度

#### 2.3 临界点检测指标
```python
def detect_critical_points(performance_curve, threshold=0.05):
    """
    检测性能急剧下降的临界点
    
    Args:
        performance_curve: [(distance, accuracy), ...] 性能曲线
        threshold: 下降阈值，默认5%
    
    Returns:
        critical_points: 临界点列表
    """
    critical_points = []
    
    for i in range(1, len(performance_curve)):
        prev_dist, prev_acc = performance_curve[i-1]
        curr_dist, curr_acc = performance_curve[i]
        
        # 计算性能下降幅度
        performance_drop = prev_acc - curr_acc
        distance_step = curr_dist - prev_dist
        
        # 检测急剧下降
        if performance_drop > threshold:
            critical_points.append({
                'distance': curr_dist,
                'performance_drop': performance_drop,
                'previous_accuracy': prev_acc,
                'current_accuracy': curr_acc,
                'drop_rate': performance_drop / distance_step
            })
    
    return critical_points
```

### 4. 临界值测试范围和步长

#### 4.1 距离范围确定依据
基于batch1/batch2的观察数据：
- **最小距离**: 0.30 (现有合成数据间的最小距离)
- **最大距离**: 1.20 (embedding空间的理论最大距离)
- **重点区间**: 0.60-0.90 (batch1未覆盖数据的主要分布区间)

#### 4.2 步长设计原理
```python
# 粗粒度扫描: 0.1步长快速定位
COARSE_STEP = 0.1
coarse_ranges = [(i, i+0.1) for i in np.arange(0.3, 1.2, 0.1)]

# 细粒度扫描: 在发现临界点附近进行0.05步长细化
FINE_STEP = 0.05
```

#### 4.3 自适应搜索策略
```python
def adaptive_search_strategy(initial_results):
    """
    基于初始结果自适应调整搜索策略
    """
    # 识别性能下降最快的区间
    critical_ranges = identify_steep_decline_ranges(initial_results)
    
    # 在关键区间进行细粒度搜索
    fine_grained_ranges = []
    for range_start, range_end in critical_ranges:
        # 将0.1区间细分为2个0.05区间
        mid_point = (range_start + range_end) / 2
        fine_grained_ranges.extend([
            (range_start, mid_point),
            (mid_point, range_end)
        ])
    
    return fine_grained_ranges
```

```python
def run_batch3_critical_distance_analysis():
    """阶段3主实验流程"""
    
    # Step 1: 数据准备
    real_data = load_real_data('batch1/base_samples/malicious_5k.csv')
    existing_synthetic = load_existing_synthetic(['batch1', 'batch2'])
```
