# 批次4重新设计方案

## 问题识别

### 原实验设计的重大缺陷
1. **数据泄露问题**: 复用batch1的固定测试集，可能与训练数据重叠
2. **数据源混淆**: 使用batch1已处理数据而非原始CEAS-08数据
3. **实验独立性**: 未从原始数据集进行干净的train/test划分

### 用户核心关切
> "合成数据有重合没关系，我担心的是test数据里，理所应当和training data不重合"
> "你似乎复用batch 1的数据，没有重新调用我的代码，用LLM生成新的synthetic data吧？"

---

## 重新设计的实验框架

### 🎯 核心原则
1. **从原始CEAS-08数据开始**: 完全独立的数据处理流程
2. **严格train/test分离**: 确保测试数据完全独立
3. **新鲜合成数据生成**: 基于新划分数据重新生成合成样本
4. **实验设计完整性**: 保持不平衡数据和内部距离分析的科学目标

---

## 新实验流程设计

### Phase 0: 原始数据预处理和划分
```
输入: raw/SevenPhishingEmailDataset/CEAS-08.csv (1,305,706 样本)
操作:
1. 数据清洗和格式化
2. 按8:2比例进行train/test划分 (随机种子=2025)
3. 提取恶意和良性样本子集
4. 生成embedding向量

输出:
- data/batch4_fresh/train_set.csv (约100万样本)
- data/batch4_fresh/test_set.csv (约26万样本) 
- data/batch4_fresh/train_malicious.csv
- data/batch4_fresh/train_benign.csv
```

### Phase 1: 质心计算和内部距离分层
```
输入: data/batch4_fresh/train_malicious.csv
操作:
1. 计算训练集恶意样本的embedding质心
2. 计算每个样本到质心的余弦距离
3. 按四分位数分层: Core/Inner/Outer/Edge
4. 可视化分层结果

输出:
- data/batch4_fresh/malicious_centroid.json
- data/batch4_fresh/stratified_layers/
  - core_samples.csv (25%最接近质心)
  - inner_samples.csv 
  - outer_samples.csv
  - edge_samples.csv (25%最远离质心)
```

### Phase 2: 分层合成数据生成
```
输入: data/batch4_fresh/stratified_layers/*.csv
操作:
1. 从每层采样种子样本
2. 使用LLM生成新的合成数据
3. 验证生成质量和成功率

输出:
- data/batch4_fresh/synthetic/
  - core_synthetic.csv
  - inner_synthetic.csv  
  - outer_synthetic.csv
  - edge_synthetic.csv
```

### Phase 3: 不平衡数据集构建
```
输入: 
- data/batch4_fresh/train_*.csv (真实数据)
- data/batch4_fresh/synthetic/*.csv (合成数据)
- data/batch4_fresh/test_set.csv (固定测试集)

操作:
1. 构建5个数据组 (real_only + 4个synthetic层)
2. 按4个比例构建训练集 (5%, 10%, 15%, 20% 恶意数据)
3. 所有配置使用相同的独立测试集

输出:
- data/batch4_fresh/datasets/
  - real_only_5pct/
  - real_only_10pct/
  - ...
  - core_5pct/
  - ...
  - edge_20pct/
```

### Phase 4: 模型训练和评估
```
输入: data/batch4_fresh/datasets/*/
操作:
1. 40个实验配置的RF和SVM训练
2. 使用固定测试集评估
3. 计算不平衡数据专用指标

输出:
- data/batch4_fresh/results/
  - 性能矩阵和对比分析
  - 内部边缘效应检测结果
  - 不平衡放大效应验证
```

## 关键改进点

### ✅ 数据独立性保证
- **完全独立的train/test划分**: 从原始CEAS-08开始划分
- **测试集固定**: 所有实验共享同一个独立测试集
- **无数据泄露**: 训练过程中绝不接触测试数据

### ✅ 实验完整性
- **新鲜合成数据**: 基于新划分的训练数据重新生成
- **分层策略保持**: 保留基于质心距离的四层分析
- **不平衡比例保持**: 5%, 10%, 15%, 20%的梯度设计

### ✅ 科学假设验证
- **内部边缘效应**: Edge层 vs Core层的性能差异
- **不平衡放大效应**: 低比例下临界点更明显
- **Baseline对比**: real_only vs synthetic层的效果差异

---

## 预期科学发现

### 假设1: 内部边缘效应存在
- **预期**: Edge层合成数据训练的模型性能显著低于Core层
- **验证**: 通过配对t检验比较各层在相同比例下的性能

### 假设2: 不平衡放大效应
- **预期**: 5%比例下的边缘效应比20%比例更显著
- **验证**: 分析边缘-核心性能差异随比例变化的趋势

### 假设3: 模型敏感性差异
- **预期**: Random Forest和SVM对内部边缘样本敏感性不同
- **验证**: 比较两个模型在各层的性能下降模式
