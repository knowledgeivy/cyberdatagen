# 阶段4: 数据不平衡和内部距离分析实验设计

## 🎯 实验动机

基于阶段3实验结果分析，我们发现：
- **Batch3局限性**: 50:50平衡数据过于"理想化"，难以揭示合成数据真实局限性
- **距离定义问题**: 与现有合成数据的距离可能不是最优的临界值指标
- **现实场景差距**: 真实网络安全场景中恶意数据比例通常5-20%

## 🔬 核心假设

1. **不平衡放大效应**: 数据不平衡会放大合成数据的质量问题
2. **内部边缘效应**: 距离真实数据质心较远的边缘样本更难被有效合成
3. **渐进式临界点**: 从核心→边缘采样会逐渐暴露LLM生成的局限性
4. **模型敏感性差异**: 不同模型对边缘样本和不平衡数据的敏感性不同

### 2. 内部距离分层策略
```python
def calculate_malicious_centroid(malicious_embeddings):
    """计算真实恶意数据的embedding质心"""
    return np.mean(malicious_embeddings, axis=0)

def stratify_by_internal_distance(malicious_data, malicious_embeddings):
    """基于内部距离进行分层"""
    centroid = calculate_malicious_centroid(malicious_embeddings)
    
    # 计算每个样本到质心的距离
    distances = [
        cosine(embedding, centroid) 
        for embedding in malicious_embeddings
    ]
    
    # 按距离四分位数分层
    q25, q50, q75 = np.percentile(distances, [25, 50, 75])
    
    layers = {
        'core': [],    # 0-25%: 最接近质心
        'inner': [],   # 25-50%: 内层
        'outer': [],   # 50-75%: 外层  
        'edge': []     # 75-100%: 最远离质心
    }
    
    for i, distance in enumerate(distances):
        if distance <= q25:
            layers['core'].append(malicious_data[i])
        elif distance <= q50:
            layers['inner'].append(malicious_data[i])
        elif distance <= q75:
            layers['outer'].append(malicious_data[i])
        else:
            layers['edge'].append(malicious_data[i])
    
    return layers, distances
```

### 5. 种子采样策略
```python
def sample_seeds_by_layer_and_ratio(layers, target_ratio, total_samples=10000):
    """
    根据层次和比例采样种子
    
    Args:
        layers: 分层后的恶意数据
        target_ratio: 目标恶意数据比例
        total_samples: 总数据集大小
    
    Returns:
        selected_seeds: 选中的种子样本
    """
    n_malicious = int(total_samples * target_ratio)
    n_seeds_per_layer = n_malicious // 4  # 每层平均分配
    
    selected_seeds = []
    for layer_name in ['core', 'inner', 'outer', 'edge']:
        layer_data = layers[layer_name]
        n_available = len(layer_data)
        
        if n_available >= n_seeds_per_layer:
            # 随机采样
            seeds = random.sample(layer_data, n_seeds_per_layer)
        else:
            # 全部使用
            seeds = layer_data
        
        selected_seeds.extend([{
            'data': seed,
            'layer': layer_name,
            'ratio': target_ratio
        } for seed in seeds])
    
    return selected_seeds
```

### 6. 增强评估指标体系
```python
def calculate_enhanced_metrics(y_true, y_pred, y_proba=None):
    """计算增强的不平衡数据评估指标"""
    
    # 基础分类指标
    metrics = {
        'balanced_accuracy': balanced_accuracy_score(y_true, y_pred),
        'cohen_kappa': cohen_kappa_score(y_true, y_pred),
    }
    
    # 少数类(恶意)专项指标
    minority_class = 1  # 假设恶意为1，良性为0
    minority_precision = precision_score(y_true, y_pred, pos_label=minority_class)
    minority_recall = recall_score(y_true, y_pred, pos_label=minority_class)
    
    metrics.update({
        'minority_precision': minority_precision,
        'minority_recall': minority_recall,
        'minority_f1': f1_score(y_true, y_pred, pos_label=minority_class),
    })
    
    # 概率相关指标
    if y_proba is not None:
        metrics.update({
            'auc_roc': roc_auc_score(y_true, y_proba[:, 1]),
            'auc_pr': average_precision_score(y_true, y_proba[:, 1])
        })
    
    return metrics
```
