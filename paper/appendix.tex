\subsection{Prompt Templates}
\label{appendix:prompts}

Complete prompt templates for synthetic spam generation across three systematically varied strategies:

\subsubsection{Original Strategy Prompt}

\begin{verbatim}
You are an expert email content analyzer. Given the following
spam email, generate a semantically similar but lexically
distinct spam variant.

Instructions: Faithfully reproduce the spam characteristics
including urgency signals, persuasive elements, and social
engineering tactics. Introduce natural lexical variation while
maintaining semantic similarity and malicious intent.

Original Email:
{original_spam_content}

Output Format (JSON):
{
  "subject": "generated subject line",
  "body": "generated email body"
}
\end{verbatim}

\subsubsection{Strong Strategy Prompt}

\begin{verbatim}
You are an expert email content analyzer. Given the following
spam email, generate a semantically similar but lexically
distinct spam variant.

Instructions: Amplify spam indicators by emphasizing urgency
signals (limited time, immediate action required), persuasive
elements (too-good-to-be-true offers, authority figures), and
social engineering tactics (credential requests, fake
notifications). Make the spam characteristics more explicit
and prominent.

Original Email:
{original_spam_content}

Output Format (JSON):
{
  "subject": "generated subject line",
  "body": "generated email body"
}
\end{verbatim}

\subsubsection{Weak Strategy Prompt}

\begin{verbatim}
You are an expert email content analyzer. Given the following
spam email, generate a semantically similar but lexically
distinct spam variant.

Instructions: Generate subtle spam with reduced explicit
indicators. Create content that appears more legitimate while
retaining underlying spam nature. Use professional language
and minimize obvious urgency signals, making the spam more
difficult to detect.

Original Email:
{original_spam_content}

Output Format (JSON):
{
  "subject": "generated subject line",
  "body": "generated email body"
}
\end{verbatim}

All prompts follow consistent JSON-formatted template structure ensuring reliable parsing and automated integration into experimental pipeline. The \texttt{\{original\_spam\_content\}} placeholder is replaced with actual spam email text during generation.

\subsection{Performance Metrics Definitions}
\label{appendix:metrics}

Classification performance metrics computed on fixed out-of-sample test set, where $TP$, $TN$, $FP$, $FN$ represent confusion matrix elements (True/False Positives/Negatives):

\paragraph{F1-Score (Primary Metric):} Harmonic mean of precision and recall:
\[
\text{F1} = \frac{2 \cdot TP}{2 \cdot TP + FP + FN}
\]

\paragraph{Supporting Metrics:}
\begin{itemize}
    \item \textbf{Accuracy:} $(TP + TN) / (TP + TN + FP + FN)$
    \item \textbf{Precision:} $TP / (TP + FP)$ - false positive control
    \item \textbf{Recall:} $TP / (TP + FN)$ - detection sensitivity
    \item \textbf{AUC-ROC:} Area under ROC curve, threshold-independent discrimination
    \item \textbf{Balanced Accuracy:} $\frac{1}{2}\left(\frac{TP}{TP+FN} + \frac{TN}{TN+FP}\right)$ - class-imbalance robust
\end{itemize}

F1-score serves as primary metric due to balanced treatment of precision and recall under 10\% class imbalance.
