\section{Evaluation}
\label{sec:evaluation}

Our evaluation systematically assesses LLM-generated synthetic spam across three complementary experimental tracks spanning 4,080 training-evaluation units. Following the methodology framework (Section~\ref{sec:methodology}), we present results organized by research questions: Track 1 evaluates synthetic data for classifier training (RQ1), Track 2a establishes baseline detection capabilities against AI-powered spam (RQ2a), and Track 2b investigates hybrid training strategies (RQ2b).

\textbf{(1) Classifier architecture fundamentally determines robustness to synthetic training data.} Random Forest demonstrates substantially higher resilience to LLM-generated synthetic spam compared to SVM across both generation models. For GPT-4.1-mini, Random Forest maintains near-baseline performance at 100\% synthetic (F1: 0.793 $\rightarrow$ 0.788-0.827, -0.6\% to +4.3\% relative), while SVM degrades significantly (F1: 0.849 $\rightarrow$ 0.617-0.735, -13.4\% to -27.3\% relative). For Claude-3.5-Haiku original prompt, Random Forest exhibits minimal degradation (F1: 0.793 $\rightarrow$ 0.796, +0.4\%), whereas SVM suffers severe performance loss (F1: 0.849 $\rightarrow$ 0.457, -46.2\%). The ensemble architecture's inherent regularization and feature subsampling mechanisms appear to mitigate distributional shift effects between synthetic and real spam.

\textbf{(2) Precision-recall trade-offs differ fundamentally between classifier architectures.} SVM exhibits extreme precision-recall asymmetry, maintaining near-perfect precision (0.95-1.00) while recall degrades substantially (0.76 $\rightarrow$ 0.30-0.60 at 100\% synthetic), resulting in overly conservative classification. In contrast, Random Forest maintains balanced precision-recall profiles (precision: 0.67-0.85, recall: 0.78-0.98) with both metrics remaining stable under synthetic data substitution. This architectural difference suggests SVM learns overly strict decision boundaries from synthetic spam, while Random Forest's ensemble voting mechanism provides more robust generalization across the real-synthetic distribution gap.

\textbf{(3) Original prompt strategy yields optimal synthetic data for SVM training, while Random Forest exhibits architecture-specific preferences.} At 100\% synthetic training, prompt strategy critically determines effectiveness. For SVM across both models, original prompts consistently outperform alternatives (GPT: original F1 = 0.735 vs strong = 0.687 vs weak = 0.617; Claude: original F1 = 0.457 vs strong = 0.414 vs weak = 0.387). This pattern establishes that faithful reproduction without artificial amplification or attenuation produces synthetic spam closest to real spam's feature distribution for margin-based classifiers. The degradation from original to weak prompts (GPT: -16.1\%, Claude: -15.3\%) demonstrates that reducing spam signal intensity introduces distributional artifacts that harm classifier training. However, Random Forest exhibits non-monotonic behavior: for GPT-4.1-mini, weak prompt synthetic data achieves highest performance (F1 = 0.827) exceeding both strong (0.802) and original (0.788), suggesting ensemble methods benefit from diverse, lower-intensity signals. For Claude-3.5-Haiku, Random Forest follows the expected pattern (original 0.796 > strong 0.727 > weak 0.637), though maintaining substantially higher absolute performance than SVM. These findings suggest practitioners should use original prompts for reliable cross-architecture performance, as artificial manipulation of spam characteristics degrades training utility for most classifiers.

\textbf{(4) GPT-4.1-mini generates substantially higher-quality synthetic training data than Claude-3.5-Haiku across all configurations.} The model-dependent quality gap proves dramatic: at 100\% synthetic with original prompts, GPT maintains 86.6\% of baseline F1 performance (SVM: 0.849 $\rightarrow$ 0.735), while Claude retains only 53.8\% (SVM: 0.849 $\rightarrow$ 0.457)—a 2-4$\times$ difference establishing model selection as the most impactful decision for synthetic data generation. Even Claude's best configuration (Random Forest + original prompt, F1 = 0.796) barely matches GPT's worst configuration (SVM + weak prompt, F1 = 0.617). This quality gap persists across all prompt strategies and classifiers, indicating fundamental differences in generation capabilities rather than prompt engineering artifacts. The superior performance of GPT synthetic data likely stems from better preservation of real spam's lexical diversity and feature co-occurrence patterns, enabling classifiers to learn decision boundaries that generalize effectively to real detection tasks.

\textbf{(5) Linear degradation patterns enable predictable performance estimation.} Figure~\ref{fig:track1} demonstrates highly linear F1 decline as synthetic ratio increases ($R^2 > 0.95$ for SVM configurations, detailed regression analysis in Appendix~\ref{appendix:degradation_models}). This linearity enables reliable interpolation for intermediate mixing ratios and predictable performance boundaries for operational deployment. Random Forest exhibits near-zero slopes across most configurations, indicating stable performance across the full synthetic ratio spectrum.

\textbf{(1) Classifier architecture determines sensitivity to training data quantity for zero-shot AI-spam detection.} As shown in Figure~\ref{fig:track2a}, SVM exhibits substantial monotonic improvement with additional real spam: for GPT detection, F1 increases from 0.744 (100 spam) to 0.881 (200 spam, +18.4\% relative); for Claude detection, F1 improves from 0.532 to 0.624 (+17.3\%). In contrast, Random Forest maintains stable or slightly declining performance (F1: 0.831 $\rightarrow$ 0.792 for GPT, 0.800 $\rightarrow$ 0.781 for Claude). This divergent behavior reflects fundamental architectural differences: SVM's margin-based learning requires more training examples to accurately position decision boundaries for distinguishing synthetic from real spam patterns, with performance scaling predictably with data quantity. Random Forest achieves near-optimal feature learning at minimal training size (100 samples) through ensemble aggregation across bootstrap samples, with additional data providing diminishing returns or slight performance degradation potentially from increased model complexity. This finding suggests resource-constrained defenders should prioritize Random Forest for zero-shot AI-spam detection, as it delivers strong performance without requiring large training datasets.

\textbf{(2) Detection difficulty varies by model and prompt strategy: original prompts produce most detectable GPT spam, while strong prompts yield most detectable Claude spam.} At baseline training (100 real spam), prompt strategy dramatically affects zero-shot detection success with model-dependent patterns. For GPT-4.1-mini synthetic spam detection, SVM achieves highest performance on original prompts (F1 = 0.744) compared to strong (0.718) and weak (0.636), while Random Forest shows near-perfect prompt invariance (F1 $\approx$ 0.830 across all prompts). This indicates original prompts produce GPT synthetic spam most similar to real spam's feature distribution, making it paradoxically both easier to detect and more useful for training. For Claude-3.5-Haiku synthetic spam, the pattern reverses: strong prompts yield highest detectability (SVM: original = 0.532, strong = 0.589, weak = 0.335; RF: original = 0.800, strong = 0.811, weak = 0.747), suggesting Claude's original prompts produce spam diverging more from real spam than strong prompts. Weak prompts universally yield lowest detection across both models, creating spam that confounds classifiers trained on real data through distributional divergence. These findings establish that prompt optimization for evasiveness differs by LLM: attackers using GPT should avoid original prompts, while attackers using Claude should avoid strong prompts to minimize detection risk.

\textbf{(3) Model-dependent baseline detectability reveals generation quality differences.} At baseline training (100 spam), GPT synthetic spam exhibits higher detectability (SVM: 0.636-0.744 across prompts, RF: 0.830-0.831) compared to Claude synthetic spam (SVM: 0.335-0.589, RF: 0.747-0.811). The 40-100\% relative difference in SVM baseline performance suggests GPT generates synthetic spam closer to real spam feature distributions while maintaining consistency, whereas Claude produces more divergent patterns. Interestingly, this higher detectability paradoxically correlates with GPT's superior performance in Track 1 (better training utility), suggesting distributional proximity to real spam enables both effective classifier training and effective detection.

\textbf{(4) Random Forest demonstrates superior prompt invariance.} Random Forest maintains remarkably consistent performance across all three prompt strategies for GPT detection (F1 $\approx$ 0.79-0.83 across all configurations, $<$5\% variance), while SVM shows 17-29\% variance across prompts. This robustness indicates ensemble methods effectively extract prompt-invariant features for AI-spam detection, providing more reliable defense against varied generation strategies.

\textbf{(1) Cross-model synthetic augmentation provides substantial but highly variable detection improvements depending on baseline performance.} As shown in Figure~\ref{fig:track2b}, training with synthetic spam from one LLM significantly improves detection of another LLM's synthetic spam, with gains ranging from moderate to dramatic. For Claude detection using GPT synthetic training data, SVM achieves improvements from baseline F1 to 100\% synthetic ranging from +29.3\% relative (original prompt: 0.532 $\rightarrow$ 0.688) to +45.8\% (strong prompt: 0.590 $\rightarrow$ 0.860) to +140.3\% (weak prompt: 0.335 $\rightarrow$ 0.805). The extreme 140\% improvement for weak prompt reflects very low baseline performance rather than exceptional augmentation effectiveness—weak prompt baseline (F1 = 0.335) represents near-random detection, amplifying relative gains despite modest absolute improvement (+0.470 F1 points). For GPT detection using Claude synthetic training data, improvements prove more modest: Random Forest achieves +8.5\% to +10.2\% relative (0.824 $\rightarrow$ 0.894-0.908 at 100\% synthetic), while SVM shows non-monotonic patterns. These findings indicate cross-model augmentation provides measurable benefits across configurations, though absolute gains matter more than relative percentages when baselines differ substantially.

\textbf{(2) Prompt-dependent augmentation effectiveness reveals generation diversity impact.} Weak prompt training data provides the largest improvements for detecting strong/original prompt synthetic spam: for Claude detection, weak prompt training at 100\% synthetic achieves F1 = 0.805 (SVM), surpassing original prompt training (F1 = 0.688, +17.0\% relative). Strong prompt training data produces intermediate improvements (F1 = 0.860). This counterintuitive pattern suggests diverse, lower-quality synthetic spam (from weak prompts) better captures the full feature space of AI-generated content, enabling more robust detection across varied generation strategies. Training on higher-quality synthetic spam (strong/original prompts) may overfit to specific generation characteristics.

\textbf{(3) Random Forest exhibits remarkable cross-model robustness with prompt-invariant detection.} Random Forest maintains stable baseline performance for Claude detection across all prompts (F1 = 0.748-0.806 at 0\% synthetic, $<$8\% variance) and achieves consistent improvements with synthetic augmentation (F1 = 0.802-0.823 at 100\% for original/strong prompts). For GPT detection, Random Forest shows perfect baseline invariance (F1 = 0.824 across all prompts) and substantial improvements at 100\% synthetic (F1 = 0.834-0.908). In contrast, SVM exhibits 40-76\% baseline variance across prompts and less consistent augmentation benefits. This indicates ensemble methods effectively extract cross-model and cross-prompt invariant features, providing reliable AI-spam detection across diverse generation conditions.

\textbf{(4) Optimal synthetic ratios exhibit complex dependencies on target model, classifier architecture, and training prompt strategy.} For Claude detection using GPT synthetic training data, most configurations show monotonic improvement with increasing synthetic ratio (0\% $\rightarrow$ 50\% $\rightarrow$ 100\%), though prompt-specific patterns vary: weak prompt training yields strongest improvements (SVM: 0.335 $\rightarrow$ 0.748 $\rightarrow$ 0.805), while original/strong prompts show similar trajectories (SVM original: 0.532 $\rightarrow$ 0.666 $\rightarrow$ 0.688; strong: 0.590 $\rightarrow$ 0.827 $\rightarrow$ 0.860). Random Forest exhibits stable or modest gains across all prompts (F1 $\approx$ 0.80 baseline, improving to 0.80-0.82 at 100\%). For GPT detection using Claude synthetic training data, patterns diverge by classifier: Random Forest consistently benefits from high synthetic ratios (optimal at 100\% across all prompts, F1 = 0.834-0.908), while SVM demonstrates non-monotonic behavior with peak performance at 50\% synthetic (F1 = 0.770-0.822) before declining at 100\% (F1 = 0.649-0.696). This SVM degradation at pure cross-model synthetic training suggests overfitting to distributional artifacts when margin-based classifiers train exclusively on synthetic spam from different LLM sources, while Random Forest's ensemble voting mechanism provides inherent regularization preventing such overfitting. The prompt-specific and architecture-specific patterns indicate practitioners must empirically validate optimal augmentation ratios for their specific deployment configurations rather than applying universal mixing strategies.

\subsection{Cross-Track Synthesis}

Comparing results across all three tracks reveals fundamental patterns in LLM-generated spam effectiveness:

\textbf{Asymmetric offense-defense dynamics with model-dependent advantages.} Track 1 shows GPT synthetic data maintains 86.6\% of baseline training effectiveness (SVM F1: 0.849 $\rightarrow$ 0.735 at 100\% synthetic with original prompts), while Track 2a demonstrates 74.4\% detection success rate (SVM F1: 0.744 for detecting GPT original-prompt spam with 100 real training samples). This indicates GPT synthetic spam proves highly effective for offensive training augmentation while remaining moderately detectable by traditional defenses. Claude exhibits opposite dynamics: only 53.8\% training effectiveness (SVM F1: 0.849 $\rightarrow$ 0.457) but also lower baseline detectability (SVM F1: 0.532), suggesting Claude generates spam that both harms training utility and evades detection. This asymmetry establishes that model selection critically determines strategic advantages: GPT favors attackers seeking training augmentation, while Claude favors attackers prioritizing evasion.

\textbf{Architectural robustness advantages with consistent ensemble superiority.} Random Forest consistently outperforms SVM across all experimental tracks. In Track 1 with Claude original-prompt synthetic data, Random Forest maintains F1 = 0.796 at 100\% synthetic while SVM degrades to F1 = 0.457 (+74.2\% relative advantage). In Track 2a Claude baseline detection, Random Forest achieves F1 = 0.800 versus SVM's F1 = 0.532 (+50.4\% relative). In Track 2b, Random Forest maintains stable or improving performance across synthetic ratios while SVM exhibits non-monotonic degradation patterns. This consistent superiority demonstrates that ensemble methods provide fundamental architectural advantages for handling distributional shifts between real and synthetic spam, and between cross-model synthetic sources.

\textbf{Cross-model feature transferability enables defensive augmentation strategies.} Track 2b demonstrates that synthetic augmentation from one LLM improves detection of another LLM's spam: Claude detection improves +29.3\% (original prompt) to +140.3\% (weak prompt) with SVM at 100\% GPT synthetic training, while GPT detection improves +8.5\% to +10.2\% with Random Forest using Claude synthetic training. These cross-model gains indicate LLM-generated spam shares underlying statistical patterns that generalize across generation sources despite model-specific variations. However, the magnitude of improvements varies substantially by baseline performance, prompt strategy, and classifier architecture, requiring practitioners to empirically validate augmentation effectiveness for specific deployment scenarios rather than assuming universal transferability.
